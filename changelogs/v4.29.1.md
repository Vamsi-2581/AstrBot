## [4.29.1] - 2026-10-17

This release absorbs the upstream 4.29.1 fixes and features that apply to this fork, together with fork work merged after 4.29.0.

### Additions

- Web Search: Added DeepSeek web search and page extraction, plus SerpApi Google web, image, finance, and scholar search tools. Providers remain configured through the ordered web search source route; SerpApi specialist tools mount when their key is configured. (#10599, #10601)
- Configuration: Added localized subtitles for single-select and multi-select configuration options. (#10601)

### Fork Additions

- BTW: Coding-agent delegations now expose normalized progress in Trace, `/work status`, and **More Features → BTW Delegated Runs**. Run summaries, event timelines, tool counts, usage, and artifacts are persisted for running and retained work sessions. (#354)

### Fixes

- Computer Use: Restored workspace-scoped file reading, writing, and editing on Windows using native file handles that reject reparse points and hardlink aliases. New installations share the same Local permission defaults on Windows, Linux, and macOS; administrators run Local code under the AstrBot account with entire-environment access and networking, without process isolation on Linux or macOS, so use workspace scope or a sandbox runtime when that trust boundary is not appropriate. When a saved policy requires isolation that is unavailable, execution fails closed without widening file scope or rewriting the saved policy. (#10584)
- Skills: Skipped unreadable local, plugin, and builtin skill directories instead of failing the entire agent request. (#10591)
- Edge TTS: Preserved the native Edge TTS SDK user agent instead of replacing it with the AstrBot user agent. (#10588)

### Fork Fixes

- Dashboard: Blocked prototype pollution in restored chat state and recovered behavior lost during the frontend deduplication refactors. (fork fix)
- Agent tools: Removed the built-in `send_poke_to_user` tool, so agents no longer poke users; use the platform `send_poke` action from Dashboard quick actions instead. This is a breaking change. (fork fix)
- Outbound HTTP: Accepted IPv6 proxy fake-ip DNS results (`2001:2::/48`) alongside the existing IPv4 range, so hostnames resolved through Clash/Mihomo IPv6 fake-ip pass validation; literal fake-ip URLs are still rejected. (fork fix)

### Fork deviations

- Local permission checks use the fork's authorization-based role model. Configuration `schema_revision` 3 advances without rewriting saved Local permission scopes, so a deliberately disabled Windows member file access stays disabled. (#10584)
- The Chinese Code of Conduct was added with this fork's maintainers as the report path. Chinese issue-template links and the upstream contact address were not adopted. (#10580)

## 中文

本版本吸收适用于本 fork 的上游 4.29.1 修复与功能，并包含 4.29.0 之后合入的 fork 工作。

### 新增

- 网页搜索：新增 DeepSeek 网页搜索与正文提取，以及 SerpApi 的 Google 网页、图片、财经和学术搜索工具。提供商仍通过有序的网页搜索来源列表配置；配置 SerpApi Key 后会挂载其专用工具。 (#10599, #10601)
- 配置：为单选和多选配置项新增本地化副标题。 (#10601)

### Fork 新增

- BTW：编码代理委派现在会在 Trace、`/work status` 和 **更多功能 → BTW 委派运行** 中展示统一进度。运行中的会话与保留的工作会话都会保存运行摘要、事件时间线、工具调用数、用量和产物。(#354)

### 修复

- 电脑使用：恢复 Windows 工作区范围内的文件读取、写入和编辑，通过原生文件句柄拒绝重解析点和硬链接别名。新安装的 Windows、Linux 和 macOS 使用相同的本地权限默认值；管理员会以 AstrBot 运行账户在整个环境执行代码并联网，Linux 和 macOS 上不使用进程隔离，若该信任边界不适合请改用工作区范围或沙盒运行时。当已保存的策略需要隔离但隔离不可用时，执行会按失败关闭，不扩大文件访问范围，也不改写已保存的策略。 (#10584)
- 技能：跳过无法读取的本地、插件和内置技能目录，避免单个目录异常导致整轮 Agent 请求失败。 (#10591)
- Edge TTS：保留 Edge TTS SDK 原生 User-Agent，不再替换为 AstrBot User-Agent。 (#10588)

### Fork 修复

- Dashboard：阻止恢复聊天状态时的原型污染，并恢复前端去重重构中丢失的聊天行为。(fork 修复)
- Agent 工具：移除内置 `send_poke_to_user` 工具，Agent 不再戳一戳用户；请改用 Dashboard 快捷操作中的平台 `send_poke` 动作。这是破坏性变更。(fork 修复)
- 出站 HTTP：在原有 IPv4 范围之外接受 IPv6 代理 fake-ip DNS 结果（`2001:2::/48`），使经 Clash/Mihomo IPv6 fake-ip 解析的主机名通过校验；直接使用 fake-ip 的 URL 仍会被拒绝。(fork 修复)

### Fork 差异

- 本地权限检查使用本 fork 基于统一授权的角色模型。配置 `schema_revision` 3 只推进版本号，不改写已保存的本地权限范围，因此用户明确关闭的 Windows 普通成员文件访问会保持关闭。 (#10584)
- 中文行为准则使用本 fork 维护者作为举报入口，未采用上游的中文 Issue 模板链接和联系地址。 (#10580)
