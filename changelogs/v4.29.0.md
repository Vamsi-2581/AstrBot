## [4.29.0] - 2026-10-14

This release includes all changes from **v4.29.0-beta.1** and **v4.29.0-beta.2**, plus changes since **v4.29.0-beta.2**. The full release range starts at **v4.28.0**.

### Major Additions

- Computer Use: Added OS-specific sandbox support for the local execution environment, available on macOS with Seatbelt and Linux with bubblewrap only. See the in-app Agent Sandbox guide under `/help/`. (#9472)
- ChatUI: Added revocable read-only conversation sharing. A session owner can create an expiring link (1, 7, 30, or 90 days, or never), list the links for one session, and revoke any of them. The public page renders a text-only transcript without Dashboard authentication and cannot reach other sessions; only the token hash is stored and the raw link is shown once. (#326, fork feature)
- ChatUI: Added opt-in multi-model parallel turns. With `dashboard.chatui_multi_model.enable` on, one prompt can run across 2–8 selected models; each answer is stored as a branch and can be switched from the reply header. Off by default. (fork feature)
- ChatUI: Added title search to the conversation sidebar. (fork feature)
- ChatUI: Added chat history and sidebar session pagination, persistent input drafts, per-session model selection, and input autofocus when switching projects. (#9667, #10279, #10247, #10301)
- ChatUI: Added provider source filters and sticky groups to model selection, plus search on the Skills and MCP pages. (#10084, #10217)
- Authentication: Added optional OIDC single sign-on with authorization-code + PKCE, single-use state and nonce, JWKS ID-token verification, and a stable `(issuer, subject)` binding to the Dashboard account. Local password and TOTP login are unchanged; auto-created accounts receive no role. (fork feature)
- Knowledge Base: Added optional Tesseract OCR for images and text-free scanned PDFs, plus an external Apache Tika extraction service. Both are off by default and configured under `knowledge_base.extraction`. (fork feature)
- Knowledge Base: Added pluggable vector stores. FAISS stays the default; a dependency-free NumPy exact backend is available through `knowledge_base.vector_store`. Existing indexes are not migrated between backends. (fork feature)
- Observability: Added default-off Prometheus metrics at `GET /metrics` and OpenTelemetry tracing spans for the pipeline and agent runs. (fork feature)
- Deployment: Added unauthenticated `GET /healthz` liveness and `GET /readyz` readiness endpoints; the bundled Compose healthchecks now use `/healthz`. (fork feature)
- Web Search: Replaced the single provider switch with an ordered `websearch_route`. Sources are queried in parallel, deduplicated by canonical URL, and fused with reciprocal rank fusion behind one `web_search` tool. Added keyless SearXNG and DuckDuckGo sources. **Breaking:** `provider_settings.websearch_provider` and the per-provider `web_search_*` tools are removed. (fork feature)
- Text-to-image output settings have **moved from Settings to Configuration Profiles → Platform → Text-to-Image** and are now configured separately for each profile; template management remains under Settings.
- Core: Added agent step budget reminders, migrated legacy limits, increased the default agent step limit, and extended shell session waits. (#10131, #10133)
- Core: Added the `x-astrbot-conversation-id` conversation ID header to provider requests. (#10218, #10237)
- WebUI: Added model settings shortcuts beside selected models and in model/fallback menus. Changes save immediately for every configuration profile using that model. (#10321)
- WebUI: Added console log search and keyword highlighting, source badges for Skills, staged image previews in ChatUI, and remembered the last opened Data & Logs tab. (#10327, #10339, #10376, #10251)
- WebUI: Added configuration profile editing in a side drawer from the bot editor. (#10310)
- Docker: Included the `astrbot` CLI for password reset inside containers. (#10442)
- Logs: Added combined level, source, plugin, platform, and keyword filtering, an option to hide user-chat logs, and font-size controls from 8–16px (12px by default, in 2px steps). Plugin selectors show display names with IDs as subtitles. (#10514)

## 中文

本正式版本包含 **v4.29.0-beta.1**、**v4.29.0-beta.2** 的全部变更，以及 **v4.29.0-beta.2** 之后的变更；完整变更范围从 **v4.28.0** 开始。

### 主要新增

- 电脑使用：本地执行环境新增按操作系统适配的沙箱隔离，目前支持 macOS Seatbelt 和 Linux bubblewrap。参见应用内 `/help/` 的 Agent 沙箱指南。(#9472)
- ChatUI：新增可撤销的只读对话分享。会话所有者可以创建带有效期的链接（1、7、30、90 天或永不过期），列出某个会话的分享链接，并随时撤销其中任意一条。公开页面无需 Dashboard 登录即可渲染纯文本记录，且访问不到其他会话；数据库只保存令牌哈希，原始链接仅显示一次。(#326，fork 专有)
- ChatUI：新增可选的并行多模型对话。开启 `dashboard.chatui_multi_model.enable` 后，一条提示词可同时交给 2–8 个所选模型运行；每条回答按分支保存，可在回复头部切换。默认关闭。(fork 专有)
- ChatUI：会话侧栏新增标题搜索。(fork 专有)
- ChatUI: 新增聊天历史和侧边栏会话分页、输入草稿持久化、按会话记忆所选模型，以及切换项目时自动聚焦输入框。 (#9667, #10279, #10247, #10301)
- ChatUI: 模型选择器新增来源筛选和吸顶分组，Skills 与 MCP 页面新增搜索。 (#10084, #10217)
- 认证：新增可选 OIDC 单点登录，使用授权码 + PKCE、一次性 state 与 nonce、JWKS ID token 校验，并按 `(issuer, subject)` 稳定绑定 Dashboard 账户。本地密码与 TOTP 登录不受影响；自动创建的账户不获得任何角色。(fork 专有)
- 知识库：新增可选的 Tesseract OCR（图片与无文本扫描 PDF）和外部 Apache Tika 提取服务。二者默认关闭，配置位于 `knowledge_base.extraction`。(fork 专有)
- 知识库：新增可插拔向量库。FAISS 仍为默认；另提供无需额外依赖的 NumPy 精确后端，通过 `knowledge_base.vector_store` 选择。已有索引不会在后端之间自动迁移。(fork 专有)
- 可观测性：新增默认关闭的 Prometheus 指标（`GET /metrics`）和流水线、Agent 运行的 OpenTelemetry 追踪 span。(fork 专有)
- 部署：新增无需认证的 `GET /healthz` 存活探针和 `GET /readyz` 就绪探针；仓库内的 Compose 健康检查改用 `/healthz`。(fork 专有)
- 网页搜索：用有序的 `websearch_route` 取代单一提供商开关。各来源并行查询，按 canonical URL 去重，再以倒数排名融合为单个 `web_search` 工具。新增免 Key 的 SearXNG 和 DuckDuckGo 来源。**破坏性变更：** 移除 `provider_settings.websearch_provider` 和各提供商独立的 `web_search_*` 工具。(fork 专有)
- 现在 “文本转图片” 的输出配置**已从 “设置” 迁移到 “配置文件” -> “平台配置” -> “文本转图像”**，并按配置文件隔离；模板管理仍保留在 “设置” 中。
- Core: 新增 Agent 剩余步数提醒，迁移旧版步数限制，提高默认步数上限，并延长 Shell 会话等待时间。 (#10131, #10133)
- Core: 为模型提供商请求新增 `x-astrbot-conversation-id` 会话 ID 请求头。 (#10218, #10237)
- WebUI：模型选择器旁及模型、回退模型菜单内新增设置入口，修改后立即影响引用该模型的所有配置文件。 (#10321)
- WebUI：新增控制台日志搜索与关键词高亮、Skills 来源标识、ChatUI 待发送图片预览，并记住「数据与日志」页上次打开的标签。 (#10327, #10339, #10376, #10251)
- WebUI：支持在机器人编辑器的侧边抽屉中编辑配置文件。 (#10310)
- Docker：镜像内包含 `astrbot` CLI，可在容器中重置密码。 (#10442)
- 日志：支持按级别、来源、插件、平台和关键词组合筛选，可隐藏用户对话日志；新增 8–16px 字号控制，默认 12px，按 2px 步长调整。插件筛选器显示插件名称，并以 ID 作为副标题。 (#10514)
