## [4.29.0] - [WIP]

### Added

- ChatUI: add revocable read-only conversation sharing. A session owner can
  create an expiring link (1, 7, 30, or 90 days, or never), list the links for
  one session, and revoke any of them. The public page renders a text-only
  transcript without Dashboard authentication and cannot reach other sessions.
  Only the token hash is stored; the raw link is shown once. (#326)
- Logs: add combined level, source, plugin, platform, and keyword filtering, an
  option to exclude user-chat logs, and font-size controls from 8–16px (12px by
  default). Plugin selectors show display names with plugin IDs as subtitles.
  (#10514)

### Optimizations

- Logs: attach structured source, plugin, platform, and category metadata for
  in-memory filtering; new logs follow the bottom only when already scrolled to
  the bottom. (#10514)

### Documentation

- Document conversation sharing under the ChatUI section in the Chinese and
  English WebUI guides, including expiry, one-time link display, revocation,
  and the read-only public page. (#326)

## 中文

### 新增

- ChatUI：新增可撤销的只读对话分享。会话所有者可以创建带有效期的链接
  （1、7、30、90 天或永不过期），列出某个会话的分享链接，并随时撤销其中
  任意一条。公开页面无需 Dashboard 登录即可渲染纯文本记录，且访问不到其他
  会话。数据库只保存令牌哈希，原始链接仅显示一次。(#326)
- 日志：新增按级别、来源、插件、平台与关键词组合筛选，可排除用户对话日志，
  并提供 8–16px 字号调整（默认 12px）。插件选择器优先显示 display name，
  副标题显示插件 ID。(#10514)

### 优化

- 日志：为内存筛选附加结构化的来源、插件、平台与分类元数据；仅当已滚动到底
  部时才跟随新日志。(#10514)

### 文档

- 在中英文 WebUI 指南的 ChatUI 小节补充对话分享说明，涵盖有效期、链接仅显示
  一次、撤销，以及只读公开页面。(#326)
