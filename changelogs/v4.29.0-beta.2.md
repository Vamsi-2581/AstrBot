## [4.29.0-beta.2] - [WIP]

Upstream synchronization window
`6b2e41791e16460bfbde3f79911f4d258c6da944..48ba71ad7477fc81c8aa99ad241f41ef5b1c0bfe`
(24 commits). Entries list only work absorbed by this fork; upstream PRs are
noted for provenance.

### Fixed

- Discord: send `Video` message components as file attachments and preserve the
  original filename for URL sources. (#10423)
- Discord: drop messages authored by the connected bot to prevent self-reply
  loops. (#10425)
- Discord: include the replied-to message text in model requests. (#10452)
- Slack: preserve inline links and user mentions inside rich-text lists, and
  keep outbound `Mention` components as `<@id>` tokens. (#10447, #10448)
- Slack: deliver TTS audio with a text fallback and preserve component order.
  (#10496)
- Media: reject unresolvable image references instead of resolving them to a
  fabricated local path, while audio, video, and file references keep their
  pending-path behavior for platform races. (#10434)
- Cron: do not record a send when no matching platform accepted the message.
  (#10468)
- Background tasks: warn when a finished result was never delivered to the
  user. (#10398)
- Agent tools: advance and close async tool generators in a single task so
  cancellation and cleanup stay deterministic. (#10474)
- Dashboard: local isolation controls now expose execution, network, and
  filesystem scope directly with an isolation setup hint and diagnostics
  dialog. (#10487)
- Dashboard: add a model-settings edit shortcut to the config-variant provider
  selector. (#10321)
- ChatUI: localize built-in LLM request errors to the requesting client locale.
  (#10478)
- WebChat: restore playback and download for user-sent audio and video.
  (#10483)
- Dashboard: preserve the last opened data workspace tab when leaving the
  workspace. (#10498)
- Dashboard: keep the mobile shell and sidebar inside the visible viewport.
  (#10512)
- QQ Official: fill `message_reference` for outbound quoted replies. (#10489)

### Changed

- Fork version tracks upstream `4.29.0-beta.2` (`pyproject.toml` and
  `astrbot/__init__.py`).

### Fork Deviations

- Upstream issue-template plugin submission links (#10455, #10472) and the
  plugin-market submit link/label (#10471): the fork issue template and
  extension page are fork-specific.
- Sidebar customization removal (#10480): the fork keeps its sidebar
  customization and diverged layout.
- Plugin view sidebar disambiguation (#10502): the fork uses Dashboard
  Extension Protocol v1 and has no legacy plugin page/view sidebar items.
- The upstream usage-documentation rewrite and screenshots from #10487: the
  fork maintains its bilingual docs independently.
- Upstream release wording and upstream-only artifact links are not copied
  verbatim; this changelog describes the features present in the fork.

### 修复

- Discord：把 `Video` 消息组件作为文件附件发送，并在来源为 URL 时保留原始文件名。
  (#10423)
- Discord：丢弃由所连接机器人自己发送的消息，避免自回复循环。(#10425)
- Discord：把被回复消息的文本纳入模型请求。(#10452)
- Slack：保留富文本列表中的内联链接和用户提及，并把出站的 `Mention` 组件保留为
  `<@id>`。(#10447、#10448)
- Slack：投递 TTS 音频时带文本回退，并保持组件顺序。(#10496)
- 媒体：拒绝无法解析的图片引用，而不是把它解析成一个伪造的本地路径；音频、视频
  和文件引用仍保留「路径稍后出现」的行为，以兼容平台竞态。(#10434)
- 定时任务：没有匹配到平台接收消息时不记录为已发送。(#10468)
- 后台任务：结果从未投递给用户时给出告警。(#10398)
- Agent 工具：在同一个任务里推进并关闭异步工具生成器，使取消和清理保持确定性。
  (#10474)
- Dashboard：本地隔离控件现在直接暴露执行、联网和文件范围，并提供隔离设置提示与
  诊断对话框。(#10487)
- Dashboard：在配置变体的提供商选择器中加入模型设置编辑快捷入口。(#10321)
- ChatUI：把内置的 LLM 请求错误按发起客户端的语言本地化。(#10478)
- WebChat：恢复用户发送的音频和视频的播放与下载。(#10483)
- Dashboard：离开数据工作区时保留上次打开的数据页签。(#10498)
- Dashboard：让移动端外壳和侧边栏保持在可见视口内。(#10512)
- QQ 官方：出站引用回复填充 `message_reference`。(#10489)
